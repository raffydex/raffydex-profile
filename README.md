# RAFFYDEX | Personal Profile Website

A modern, responsive personal portfolio website built to establish my digital presence, showcase my interests, highlight my experiences, and provide a central platform for professional connections.

---

## Overview

**RAFFYDEX Personal Profile Website** is a personal website designed to introduce who I am, what I do, the fields I am interested in, and the experiences I have gained through learning and practical involvement.

The project focuses on creating a clean, modern, and accessible user experience across different screen sizes and devices.

It also serves as a practical frontend development project through which I applied fundamental web development concepts, including semantic HTML, CSS styling, responsive layouts, and JavaScript-based interactivity.

## Objectives

The primary objectives of this project are to:

- Establish a professional online presence.
- Present my academic background, interests, and professional experiences.
- Showcase selected projects and learning experiences.
- Practise and strengthen frontend web development skills.
- Provide accessible channels for professional communication and networking.
- Build a foundation for future improvements and additional web development projects.

## Getting Started

Follow these instructions to run the project on your local computer.

### Prerequisites

You will need:

- A computer running Windows, macOS, or Linux.
- A modern web browser.
- Visual Studio Code or another code editor.
- Git (optional, for cloning the repository).

### Installation

**Option 1: Clone the Repository**

Open your terminal and run:

```bash
git clone https://github.com/raffydex/raffydex-profile.git
```

Navigate into the project directory:

```bash
cd raffydex-profile
```

**Option 2: Download the Project**

1. Open the repository on GitHub.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded folder.
5. Open the extracted folder in Visual Studio Code.

### Running the Website

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Launch the page using the Live Server extension, or open the HTML file directly in your browser.

The website should now be accessible locally.

## Customization

The project can be modified to reflect new information, experiences, and design preferences.

### Updating Personal Information

Edit the relevant sections inside `index.html`.

### Changing the Profile Photograph

Replace `images/profile.png` with your preferred photograph while keeping the filename and image path consistent.

### Modifying the Website Appearance

Edit `css/style.css` to customise:

- Colours and themes.
- Typography.
- Spacing and layouts.
- Responsive breakpoints.
- Visual effects and animations.

### Updating Interactive Features

Edit `js/script.js` to modify existing JavaScript functionality or introduce additional interactions.
